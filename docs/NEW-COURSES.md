# LearnWithUs v2.6.0 — Science & Discovery + Smarter Maths

## How to find it in your website

1. Open **Kids Corner** (`children.html`). Scroll to **Explore by learning area**.
2. Expand **Science & Discovery** and select S5–S15.
3. Under the category cards below, see the standalone **🔬 Science & Discovery** category, with the same green/yellow card styling.
4. Open **Quiz Hub**, select **Science & Discovery** and launch the matching quiz.
5. Expand **Maths & Numbers**, select M12–M21, or use their category cards. These quizzes are inside the existing **Maths** Quiz Hub section.

All learning pages use **Learn → Practise → Quiz**, with previous/next navigation, spoken feedback and existing score-card/progress hooks.

## Compatibility

- **Core Journey remains exactly 18 steps.**
- English & Reading remains E1–E14 (the complete v2.4.0 reading upgrade).
- All existing URLs, quiz records, name/score-card support and local progress data (`learnwithus.platform.v1`) are retained.
- Both `public/` and `dist/` contain identical release assets.
- Browser-dependent speech remains optional and the site does not save voice recordings for these lessons.
- Hands-on science activities need adult supervision.
- All 10-question quizzes validate one answer at a time and use matching Quiz Hub categories.

## Future changes

Add future Science steps after S15 and Maths steps after M21 without modifying the Core Journey. Follow the existing shared data registry and topic query routing conventions; keep compatibility routes intact.
